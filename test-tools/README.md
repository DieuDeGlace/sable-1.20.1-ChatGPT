# Sable Test Tools

Optional Forge 1.20.1 tools for testing a locally built Sable mod:

- selection wand;
- gravity gun; and
- test-session configuration commands.

Build from the repository root with `build-with-test-tools.cmd`. The test mod is
kept separate from the production Sable JAR and is intended only for disposable
test worlds.
